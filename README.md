# Bible Side by Side

Pick two Bible versions (or paste your own text), line them up verse by verse,
add room for handwritten notes, and save the result as a PDF.

Everything runs in the browser. Pasted text never leaves the visitor's device.

## Bible text
`data/` holds public-domain translations from
[scrollmapper/bible_databases](https://github.com/scrollmapper/bible_databases),
split into one file per book by `scripts/build_data.py`.
Copyrighted versions (NIV, ESV, NKJV, …) aren't included, but can be pasted in.
